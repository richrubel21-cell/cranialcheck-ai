# CranialCheck AI

Zero-hardware neurological screening — browser-based, field-deployable. A product of **PredictWell Health AI**.

CranialCheck AI runs MediaPipe FaceLandmarker entirely in the browser (WebAssembly) to assess oculomotor function, 10 cranial nerves, and speech motor analysis from any smartphone — no hardware, no app, no connectivity required.

## Pages

- **Landing:** `index.html`
- **Live demo (TRIAGE screen):** `cranialcheck-demo.html`
- **Admin dashboard:** `admin.html`

**GitHub Pages: https://richrubel21-cell.github.io/cranialcheck-ai/**

## Stack

- MediaPipe Tasks Vision (FaceLandmarker, in-browser via WASM)
- Supabase (exam records storage, West US)
- Static HTML/CSS/JS — no build step
